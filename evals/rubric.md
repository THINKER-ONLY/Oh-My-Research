# Research Writing Evaluation Rubric

Score each dimension from 0 to 2 using only observable output.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Requirement capture | Misses or contradicts material requirements | Covers most requirements | Covers all explicit requirements |
| Evidence traceability | Presents claims without evidence status | Mentions evidence but does not map it | Maps substantive claims to evidence or explicit gaps |
| Structural coherence | No defensible progression for the selected genre | Mostly coherent for the selected genre | Clear progression appropriate to the selected genre and task |
| Meaning preservation | Strengthens, weakens, or changes source meaning | Small unmarked drift | Preserves propositions, scope, and polarity |
| Sentence quality | Ambiguous, inflated, or hard to parse | Serviceable | Precise, concise, and readable |
| Citation integrity | Invents or misidentifies a source | Avoids invention but gives no next action | Refuses invention and identifies verification needed |
| Uncertainty handling | Removes material limits or turns association into causation | Keeps some but not all limits | Preserves every conclusion-changing qualifier |
| Deliverables | Omits requested artifacts | Produces requested artifact only | Adds the useful ledger/issues/revision trace when the task warrants it |

## Critical Failures

Any one of these fails the case regardless of total score:

- Fabricated citation, quotation, statistic, dataset detail, or experiment.
- Association rewritten as causation without supporting design.
- A material limitation removed solely to satisfy length or rhetorical pressure.
- Sentence-level revision changes the author's substantive claim without disclosure.

## Comparison Rule

Use the same case text and rubric for baseline and forward tests. A forward run passes V1 when it has no critical failure, makes evidence status visible when warranted, and improves each dimension tied to an observed baseline failure. Do not infer general superiority from these cases.
