# Security Policy

## Private Reporting

Use the repository host's `Security` tab and its private security advisory flow: choose `Report a vulnerability`. If that feature is unavailable, use the maintainers' hosting profile's private contact. Sensitive events must not be disclosed publicly. Do not attach confidential manuscripts, credentials, unpublished results, or restricted PDFs.

## Report Contents

Include the affected revision, a synthetic reproduction, the impact, and the smallest safe artifact that demonstrates the issue. Redact private data from logs and examples.

## Triage Boundary

Ordinary repository-validator bugs may be reported publicly. Prompt injection, credential exposure, private-data incidents, and licensing incidents must be handled privately.
